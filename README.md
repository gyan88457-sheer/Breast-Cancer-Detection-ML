# Breast Cancer Detection ML

## Project Overview
This project uses Machine Learning to detect breast cancer based on medical diagnostic data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model
- Logistic Regression

## Dataset
Breast Cancer Dataset (data.csv)

## Features
- Data Preprocessing
- Feature Scaling
- Train-Test Split
- Logistic Regression Classification
- Model Evaluation
- Model Saving using Pickle

## Files
- Breast_Cancer_Detection.ipynb
- data.csv
- breast_cancer_model.pkl
- scaler.pkl
